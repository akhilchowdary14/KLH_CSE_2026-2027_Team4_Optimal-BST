## Abstract

The Optimal Search Tree is a software application designed to construct a Binary Search Tree using the search frequencies of different keys. In a normal Binary Search Tree, frequently searched keys may not always be placed in the best position, which can increase the overall search cost. This project aims to arrange the keys in an efficient way to reduce the average search cost.

The system takes a set of distinct keys and their search frequencies as input. It uses the Dynamic Programming technique to find the best possible arrangement of the keys. The program checks different possible root nodes and calculates the cost of each arrangement. It then selects the arrangement with the minimum expected search cost.

The application displays the resulting Optimal Binary Search Tree and shows its minimum search cost. This makes it easier for users to understand how the position of a key affects searching efficiency.

The main objective of this project is to demonstrate the practical use of Dynamic Programming in solving an optimization problem. Overall, the project provides a simple and easy-to-understand implementation of an Optimal Binary Search Tree and helps improve the efficiency of searching frequently accessed keys.

## Setup

### Requirements

* Java JDK
* IntelliJ IDEA / Eclipse / Visual Studio Code
* Git

### Clone the Repository

```bash
git clone https://github.com/prabandalarevanth137/Team-4_Optimal-Binary-Search-Tree.git
```

### Run the Project

Open the project in **IntelliJ IDEA, Eclipse, or Visual Studio Code**.

If the main file is `OptimalBST.java`, compile and run it using:

```bash
javac OptimalBST.java
java OptimalBST
```

The program takes distinct keys and their search frequencies as input and displays the **Optimal Binary Search Tree** and its **minimum search cost**.
